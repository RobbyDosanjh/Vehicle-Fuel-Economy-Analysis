# Vehicle Fuel Economy Analysis

Exploratory data analysis of EPA vehicle fuel economy data using R.

## Overview

This project explores EPA vehicle fuel economy data using R. The goal is to examine vehicle characteristics and evaluate combined city/highway fuel economy across passenger vehicles.

This analysis was completed as part of my graduate Data Science coursework and demonstrates foundational skills in exploratory data analysis, data inspection, and visualization.

## Skills Demonstrated

* R
* Exploratory Data Analysis (EDA)
* Data importing and inspection
* Data cleaning
* Data visualization
* ggplot2
* Interpreting patterns in vehicle fuel economy data

## Dataset

The dataset comes from the U.S. Environmental Protection Agency's FuelEconomy.gov database and contains vehicle information spanning model years 1984–2025.

Source: FuelEconomy.gov

## Analysis

The project includes:

* Importing vehicle data into R
* Examining the structure of the dataset
* Identifying relevant variables
* Exploring combined city/highway fuel economy
* Creating visualizations to identify trends and patterns
* Interpreting results from exploratory analysis

* R
* RStudio
* tidyverse
* ggplot2
